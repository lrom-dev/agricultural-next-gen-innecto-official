ROLE:

TASK:
This is a dry run. Create a social media web app able to satisfy the following requirements:

Objectives:

2. 1. PC;
2. tablet;

5. Is the web application’s main thread activity breakdown < 10% when active for 5 minutes?

Web App Features

1. User Profiles (Login and Signup)
2. Content Creation and Sharing (User and Anonymous)
3. Central Feed
4. Interactivity
5. Messaging
6. Search and Discovery

OUTPUT & THEME:

1. A social media web application optimized for mobile devices.
2. The web app’s theme is Mindanao: Agriculture, Innovation, and Connection.

CONSTRAINTS:
